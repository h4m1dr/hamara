# قالب پیامک‌ها برای پارسر — بدون شماره و مبلغ واقعی

همه شماره حساب/کارت، مانده و مبلغ واقعی حذف شده؛ فقط ساختار نگه داشته شده.

## ۱. تجارت
```
*بانک تجارت*
حساب: <account>
برداشت: <amount> ریال        (یا واریز:)
از طریق: <channel>            (شتاب / خودپرداز / شعبه / پایا ...)
مانده: <balance> ریال
<1405/08/25>
<13:06>
```
- کلمه «برداشت/واریز» + «ریال» صریح است. تاریخ شمسی کامل + ساعت در خط جدا.

## ۲. پاسارگاد / ویپاد
```
<account.with.dots>
-<amount>                     (برداشت؛ واریز با +)
<MM/DD_HH:MM>                 (بدون سال)
مانده: <balance>
```
- هیچ کلمه برداشت/واریز و هیچ «ریال» نیست؛ فقط علامت + / -.
- تاریخ بدون سال است؛ سال باید از تاریخ دریافت پیامک گرفته شود.

## ۳. ملت
قالب کوتاه:
```
حساب<account>
برداشت<amount>
مانده<balance>
<YY/MM/DD-HH:MM>              (سال بدون «14»)
```
قالب بلند (پرداخت بدهی = برداشت):
```
بانک ملت
مشتری گرامی، پرداخت بدهی ش.ق
بمبلغ <amount> ریال از محل حساب بشماره <account> انجام شد.
<1405/08/07 05:45>
```
پیام‌های غیرتراکنشی که پارسر باید نادیده بگیرد:
- «دیما / <نام> عزیز خوش آمدید» + تاریخ
- «بانک ملت / به سامانه همراه بانک ملت خوش آمدید» + تاریخ

## تفاوت‌هایی که پارسر باید هندل کند
- سه قالب تاریخ: کامل شمسی (تجارت)، ماه/روز_ساعت بدون سال (پاسارگاد)، سال کوتاه با خط تیره (ملت).
- نوع تراکنش: کلمه صریح (تجارت/ملت کوتاه)، علامت + / - (پاسارگاد)، جمله «پرداخت بدهی … انجام شد» (ملت بلند = برداشت).
- واحد: «ریال» فقط در تجارت و ملت بلند هست؛ در پاسارگاد و ملت کوتاه نیست — پیش‌فرض ریال، نمایش تومان = تقسیم بر ۱۰.
