# لیست ساخت فاز ۱

## راه‌اندازی (یک بار)
1. `npm install`
2. `npx wrangler login`
3. `npm run db:create` — `database_id` برگشتی را در `wrangler.toml` بگذار
4. `npm run db:schema`
5. بات در BotFather بساز؛ یوزرنیم با اسم hamara چک شود که گرفته نباشد
6. سکرت‌ها: `wrangler secret put TELEGRAM_BOT_TOKEN` و `TELEGRAM_WEBHOOK_SECRET`
7. `ALLOWED_TELEGRAM_ID` در `wrangler.toml` = آیدی عددی تلگرام مالک
8. `npm run deploy` و ست کردن وب‌هوک تلگرام به `/telegram` با همان سکرت
