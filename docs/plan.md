# پلن hamara — نسخه فعلی (تک‌نفره)

## الان چه می‌سازیم
- مدیریت مالی **فقط برای یک نفر** و حساب‌های بانکی خودش.
- بات تلگرام + مینی‌اپ، نه برنامه نیتیو. بات فقط مینی‌اپ را باز می‌کند و فایل/متن می‌گیرد؛ کار اصلی داخل مینی‌اپ است.
- دسترسی فقط با allowlist آیدی تلگرام؛ برای بقیه باز نیست.
- Cloudflare Workers + D1 (+R2 در صورت نیاز)، بدون سرور؛ سرور فقط اگر محدودیت (مثلاً PDF) مجبور کرد.

حساب مشترک و جدا/مشترک کردن دو نفر برای بعد است — الان طراحی نمی‌شود.

## ورودی‌ها (به ترتیب واقعی)
1. فایل CSV/PDF خروجی صورت‌حساب بانکی — مسیر اصلی.
2. متن پیامک به بات — برای تست و شروع؛ قالب‌ها در `parsers.md`.
3. ورود دستی فقط داخل مینی‌اپ، نه دستور متنی بات.
4. فعال‌کردن پیامک + خواندن خودکار اندروید — بعداً، اختیاری.

## نمایش و گزارش
- تم روز/شب؛ روز شبیه لیست کارتی گردش حساب ویپاد، گروه‌بندی با روز.
- چیپ بالا: «همه» + هر بانک اضافه‌شده. نوع انتقال (پایا/کارت‌به‌کارت/…) داخل آیکون فیلتر.
- فیلتر: بین بُعدها ترکیب (بانک × دسته × نوع)، داخل هر بُعد تکی — یک تراکنش نمی‌تواند هم پایا باشد هم کارت‌به‌کارت، در دو بانک باشد، یا در دو دسته باشد.
- یادداشت/تگ و دسته روی خود کارت لیست دیده شود، نه پنهان در جزئیات.
- رنگ هر دسته در تنظیمات؛ روی آیکون، برچسب و قاب کارت.
- نمودار: دونات/کیک دسته‌ها + میله‌ای ماهانه دخل/خرج. انتقال داخلی بین بانک‌های خودمان دسته جدا دارد ولی در جمع دخل/خرج نمی‌آید.
- خروجی: تراکنش‌ها اکسل/شیت (CSV) + خروجی تنظیمات.

## تصمیم‌های باز
1. پایه: فورک معماری tapwork-kz یا ساخت از صفر با همان الگوی Workers+D1؟
2. ستون‌های واقعی خروجی CSV ویپاد چیست؟ بدون نمونه (حتی فقط سرستون‌ها) آداپتر ویپاد ساخته نمی‌شود. PDF روی Workers هم باید تست شود.
3. قانون تطبیق انتقال داخلی (مبلغ برابر + چه بازه‌ای؟) و قانون سال برای تاریخ بدون‌سال پاسارگاد در حالت مرزی.
